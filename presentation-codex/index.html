The HTML presentation works offline as a single file. Use the arrow keys or Previous/Next. Press N for notes. “Script & sources” opens the complete narration. The timing labels are pacing targets, not an automatic countdown.

The script contains eight timed sections totaling ten minutes, followed by source notes that are not part of the talk. Rehearse once to adapt the pacing to your delivery.

To rebuild, run python3 build.py in this folder. This needs pdfLaTeX and Poppler (pdftocairo). To check the scientific summaries, run ../.venv/bin/python validate.py from this folder. The latter also reads the parent project’s archived data and needs SymPy.

The talk summarizes the existing research. No fresh nonlinear solver runs were performed for this presentation. The historical usage report records active agent time, not total CPU/GPU computation time.

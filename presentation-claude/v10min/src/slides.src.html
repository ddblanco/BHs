The question: how far does Gauss–Bonnet move the extremal bound?
Warm-up: Kerr, 4D (G = c = 1, a = J/M)
Extremality: J ≤ M2. At J = M2 the horizons merge and
T = √(M2 − a2) / (4πMr+) = 0.
First law: dM = T dS + ΩH dJ, with T = κ/2π, S = A/4.

Einstein, 5D, two equal spins J:

M ≥ 32π1/3J2/3

saturated by an extremal (T = 0) black hole.

Add Gauss–Bonnet with coupling α:

R + α 𝓛GB

schematically R ~ g ∂2g + ∂g ∂g, 𝓛GB ~ R2

Known: slope π at first order in α
Ma, Li, Lü, arXiv:2009.00015

Asked: the slope at finite α.

A1 · Numerical method: solving the field equations
Equal-spin ansatz ⇒ ODEs in r for b, f, h, w:
ds2 = −b dt2 + dr2/f + r2[dθ2 + sin2θ cos2θ (dφ1 − dφ2)2]
  + h [sin2θ dφ1 + cos2θ dφ2 − w dt]2
horizon: b = f = 0, w = ΩH;  infinity: b, f, h/r2 → 1, w → 0
Discretise: χ = 1 − rH/r, Chebyshev–Lobatto, N = 64: RN(u; α, rH, ΩH) = 0 (4N eqs.)
Solve: damped Newton; continuation from Myers–Perry
Accept: Gμν + αHμν < 10−8 at 51 off-grid points
Read off: b ≃ 1 + U/r2, w ≃ W/r4 ⇒ M = −3πU/8, J = πW/4
A2 · Numerical method: measuring Ψ and reaching T = 0
Ψ from derivatives at fixed (rH, ΩH)
Ψ = ∂M∂αS,J = Mα − T Sα − 2ΩH Jα
Derivatives without finite differences
∂RN∂u dudα = −∂RN∂α
matrix = Newton Jacobian: one linear solve, no step size (implicit function theorem)
Get cold, then extrapolate
cubic fit through the 6 coldest states;
coldest TJ1/3 ≈ 3×10−6

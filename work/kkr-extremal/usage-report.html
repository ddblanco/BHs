How to read these figures

  • The first version of this page gave 5 to 5.5 hours of actual computing. That was a rough overlap estimate; the overlap is now measured from the run timestamps.
  • NumPy runs multithreaded, so CPU time exceeds wall time: the last branch phase used about 60 min of CPU in 44 min.
  • The branch stopped at x = 0.863, short of KKR's x ≈ 0.92. That is a limit of the method (constraint violation next to the horizon at the highest usable resolution), not of running time.
  • The symbolic-generation row includes a 13-minute symbolic attempt that failed and was replaced by a numerical one.

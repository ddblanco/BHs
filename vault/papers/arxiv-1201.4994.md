## Derived here (D=5, G=1, J=0)

- Small static EGB holes: μ = r_h² + 2α, ΔM = M − 3πα/4 = 3π r_h²/8,
  T = r_h/(8πα) (leading order), S = 6π²α r_h. First law dM = T dS holds.
  Equivalent BTZ data: ℓ² = 4α, 1/(4G₃) = 3πα.
- The critical static solution μ = 2α (M = 3πα/4) is the massless-BTZ analogue; it is the
  J → 0, α → ∞ endpoint of the extremal branch ([[extremal-mass-strong-coupling]]).
- If the extremal rotating core were *this* BTZ, the exact strong-coupling throat entropy
  S² → 48π³ α^(3/2) J would give ΔM = S²/(48π³α²) = J/√α (coefficient 1). The matched
  candidate and the numerical fits give 4/3. The rotating throat is strongly squashed
  (h_H/g_H → 0), so the round-core BTZ dictionary does not apply as it stands.
